# Pause-aware alignment and interactive voice coaching

Owner explicitly requested implementation of the proposed pipeline, GPU testing, a measured recognition comparison and preservation of avatars/session UX. The follow-up permits TTS/LLM aid; use existing offline Tamil TTS, without a cloud API/LLM or unattended microphone. This design concretizes that already-authorized work.

Authority: DEC071/PHN012/COA001 in SSOT3.3.62. Prior DEC070/PHN011 and clinical abstention remain.

## Approach and scope

Separate target-free audio preprocessing/phoneme decoding from target-conditioned diagnostic alignment. A constrained posterior-to-reference sequence aligner tolerates time stretching/pauses while exposing support/uncertainty and allowing skipped reference phones. It must never manufacture the expected token sequence as a recognition output. DTW over raw MFCC templates is not selected: speaker/pitch differences and compulsory template matching would conflate similarity with correct speech. Refitting weights is out of scope for this isolated timing experiment.

Implement a pure conservative PCM pause compactor: identify interior very-low-energy runs, preserve 60ms context per side and at least80ms of the pause, remove only long runs >=300ms, never alter voiced samples, retain a sample/time map. No clipping normalization, global vowel/double collapse or tail deletion. Silence and weak recordings stay uncertain. Candidate compaction is measured offline first; production capture only changes if the predeclared nonregression panel passes. Existing three-second graph limit remains; never silently truncate. Long originals get explicit supplementary accounting.

Implement bounded frame-posterior/reference edit alignment with explicit insertion/deletion, blank/silence handling and reference-independent decoded evidence. It reports transient diagnostic support, not a child score; ambiguous/unsupported reference or invalid posterior abstains. Preserve repeated phones/long vowels. Do not identify /ʃ/->/s/: /ʃ/ is not a distinct supported native model unit. Existing /ʂ/ must not be relabelled as /ʃ/.

GPU experiment: fixed FP32 model/checkpoint, beam5/top8 unchanged. Reproduce saved baseline73complete-child-clip predictions before paired candidate inference on all133recordings. Primary metric remains the same73closed-reference complete clips against owner-verified text-derived references. No hidden exclusions or forced alignment in raw PER. Record unchanged/better/worse counts; exposed labels/data are development diagnostics, not independent clinical validation. Three existing public calibration controls and a fixed small public speech/pause panel protect obvious regressions; no1665cohort repeat. Source/model/archive/reference identities frozen before inference. Synthetic pauses/quiet gain test recording variations, not simulated disorders. Never tune parameters after looking at candidate results. Persist only small local private research outputs outside Git; no new model copies/audio extraction/uploads.

Voice coach uses closed original Tamil/English captions. Distinguish observed capture issues (too quiet/clipped/too long) from sound hypotheses. It can say it could not hear clearly, invite comfortable pace or demonstrate target sound/syllable/word; it cannot assert a child omitted/substituted a sound. Timing alone never diagnoses slow/fast speech. Praise remains effort-based and round-triggered; no new sticker trigger. Audio callbacks remain foreground/identity/generation owned, bounded and cancellable, honor voice-off, and never overlap Record/Stop/capture. No automatic retries or new navigation, avatar or session stages.
